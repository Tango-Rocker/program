# TICKET ID: DOC-002-architecture-drift-review

## Objective

Review architecture docs against implemented systems and correct drift.

## Context

The docs are working contracts for agents. After several implementation sprints, stale docs become a source of defects.

## Sprint

Sprint 11 - polish and architecture rework pass.

## Acceptance criteria

- Compare docs against implemented modules and ticket outcomes.
- Update module maps, testing docs, known issues, and doctrine notes where implementation changed.
- Remove or mark stale statements that imply completed behavior where none exists.
- Add explicit future-ticket references for deferred gaps.
- Add a session archive entry summarizing drift found and fixed.
